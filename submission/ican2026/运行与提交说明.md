## 最小运行方式

1. 安装Python 3.11。
2. 在项目根目录创建虚拟环境并安装开发依赖：`pip install -e ".[dev]"`。
3. 启动服务：`uvicorn app.main:app`。
4. 浏览器访问：`http://127.0.0.1:8000`。

未配置专业模型时，系统会显式启用Demo检测器，基础闭环仍可运行，但页面会记录fallback状态，不能把该结果作为专业模型效果证明。

## 比赛完整运行方式

Windows比赛机在项目根目录执行：

`powershell -ExecutionPolicy Bypass -File scripts\start_competition.ps1`

脚本会检查YOLO权重及摘要，启用本地火情分类环境和本地大模型（条件具备时），并启动网页。服务启动后先点击“运行赛前环境自检”，确认专业视觉模型、火情复核模型、本地大模型、安全知识库、Agent工具、验证案例和报告导出均为就绪状态。
