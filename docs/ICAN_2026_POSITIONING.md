# VisionGuard AI - iCAN 2026参赛定位

## 参赛身份

- 大赛：2026年iCAN大学生创新创业大赛
- 专项赛事：AI应用创新挑战赛
- 参赛赛道：软件赛道
- 参赛组别：高校组
- 项目名称：VisionGuard AI
- 项目副标题：面向工业安全场景的多模态视觉风险智能体

VisionGuard AI以可在线演示或可运行的软件作品参赛。项目不是iCAN主赛“创新赛道”项目，也不参加硬件赛道；FactorySafe及其数字孪生、路径规划等能力不纳入本项目。

## 一句话定位

VisionGuard AI以专业视觉模型获取可信现场证据，以大语言模型理解任务和解释风险，以智能体编排检测、知识检索、风险分析与报告工具，形成“感知-理解-推理-决策辅助”的工业安全闭环。

## 评审指标对齐

### 1. 创新性（30分）

从传统视觉系统“检测目标并报警”升级为面向任务闭环的工业视觉智能体；以专业模型取证、大模型解释、知识约束和证据编号校验形成差异化，避免被理解为普通YOLO项目或无约束聊天机器人。

### 2. 技术实现（30分）

以真实可运行链路证明AI运用深度：专业视觉检测与多模型复核输出结构化证据，Agent完成工具编排，本地大模型执行证据约束解释，混合RAG提供知识依据，并通过确定性回退保证系统可用性。所有性能数据必须注明模型、阈值、数据集、硬件和运行配置。

### 3. 实用价值（20分）

面向制造企业、仓储区域、工业园区和设备运维场景，为人工巡检与传统视觉报警之间补充风险理解、依据检索和报告生成能力。系统定位为安全辅助分析工具，不替代现场人员、企业制度或法定事故认定。

### 4. 用户体验（10分）

围绕比赛展示固定核心路径：上传现场图片和输入任务，查看检测框与证据位置，获得风险等级、原因、知识依据和处置建议，继续追问并导出结构化报告。界面应保持步骤清晰、反馈及时、异常可恢复。

### 5. 展示效果（10分）

应用方案与演示视频使用同一条主线，集中呈现“用户请求-Agent编排-视觉取证-知识增强-风险推理-报告输出”，通过真实运行画面和量化证据突出核心优势，不加入数字孪生、路径规划等分散主题的功能。

## 官方提交要求

1. 应用方案：PDF格式，不超过20页。内容应覆盖项目背景与痛点、需求分析、目标用户与功能需求、开发工具、技术方案、逐项功能、AI核心作用、完整使用说明、应用前景和商业模式。
2. 演示视频：MP4格式，不超过5分钟。应全面展示功能和操作流程，突出智能体接收请求、分析决策、反馈结果及与其他模块协同工作的过程，并体现实际应用价值与优势。
3. 可运行程序：网页或智能体应用应提供稳定可访问的运行链接，或提交应用程序源代码。
4. 时间节点：官网报名和提交作品截至2026年9月30日；10月线上复赛；11月全国总决赛现场比赛。
5. 团队要求：高校组每队2-5人，指导教师不超过2人；报名结束后不可修改团队信息，指导教师不能作为团队成员。

答辩PPT可作为全国总决赛现场展示材料提前准备，但通知列明的报名提交物核心是应用方案、演示视频和可运行程序，不应把PPT写成当前报名阶段的强制提交件。

## 与原比赛口径的变化

| 原人工智能命题口径 | iCAN AI应用创新挑战赛口径 |
|---|---|
| 围绕指定命题逐条满足技术指标 | 自主选题，按创新性、技术实现、实用价值、用户体验和展示效果综合评审 |
| “识别准确率大于90%、时延小于2秒”作为命题指标 | 不是本挑战赛统一门槛，但仍以真实、可复现指标证明技术质量 |
| 作品简介与技术方案说明分开组织 | 合并形成不超过20页的应用方案，并配套5分钟内演示视频与可运行程序 |
| 强调符合“基于智能视觉分析的智能体应用开发”命题 | 强调AI在作品中的核心作用、完整产品体验、行业价值与差异化优势 |

## 项目边界

- 继续使用独立的VisionGuard AI仓库和现有v0.12.0产品能力。
- 不复制、不合并、不修改FactorySafe或FactorySafe Twin。
- 不增加数字孪生、复杂路径规划、多机器人等偏离主线的功能。
- 已完成能力按验证结果陈述；未来能力、产业合作与商业数据不得写成既有成果。
