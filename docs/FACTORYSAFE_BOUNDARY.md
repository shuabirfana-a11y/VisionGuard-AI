# 与 FactorySafe 的项目边界

## 项目关系

VisionGuard AI 是全新、独立的比赛项目。两个项目没有代码依赖、仓库继承或产品合并关系。

## VisionGuard AI 当前范围

- 图片上传与自然语言任务输入
- Agent 工具注册与调用编排
- 专业视觉检测适配接口
- 结构化视觉证据
- 安全知识检索
- 风险分析与结构化报告

## 明确不纳入本阶段

- FactorySafe 原有工业火灾安全系统的业务代码
- 数字孪生与复杂三维场景
- 路径规划
- 人员核查
- 事件管理
- 多机器人协同

## 复用原则

只允许复用通用工程经验与公开技术知识，不复制 FactorySafe 源码、配置、模型资产或仓库历史。任何未来跨项目复用都必须先进行授权、许可证和技术必要性审查。
