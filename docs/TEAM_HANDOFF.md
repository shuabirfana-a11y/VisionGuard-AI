# 队友交接与验收清单

## P0-A：真实火焰/烟雾视觉模型

分支：`feat/real-yolo-model`

交付：

- 合法数据来源和许可说明；
- 训练、验证、独立测试划分；
- 可配置YOLO权重及文件摘要；
- Precision、Recall、F1、mAP、误报率和推理时间；
- 典型误报与漏报案例；
- 接入现有 `YoloVisionDetector`，不得绕过统一证据结构。

验收：测试集固定、指标可复现、页面明确显示真实模型版本且未发生Demo回退。

## P0-B：真实大模型可信推理

分支：`feat/llm-reasoning`

交付：

- 配置兼容大模型服务；
- 至少30个固定测试案例；
- 合法证据引用、虚构引用拦截和服务失败回退结果；
- 模型名称、版本、响应时间和调用成功率。

验收：不得绕过 `CompatibleLLMReasoner` 的证据编号校验，不得提交密钥。

## P0-C：正式安全知识语料

分支：`feat/safety-knowledge`

交付：

- 可授权使用的规范来源清单；
- 发布机构、版本、日期、章节和原文定位；
- 结构化切片与检索索引；
- 检索正确率测试和错误引用案例。

验收：报告中的每个知识引用可回溯原始来源，内部草案与正式规范清楚区分。

## P0-D：独立评测与对比实验

分支：`feat/evaluation-suite`

交付：

- 固定评测集和批量评测入口；
- YOLO单模型与VisionGuard AI完整闭环对比；
- 检测性能、工具调用正确率、报告质量和响应时间；
- 原始结果、汇总表和图表生成步骤。

验收：所有结论能够从原始结果复算，不允许手工填写或补造指标。
