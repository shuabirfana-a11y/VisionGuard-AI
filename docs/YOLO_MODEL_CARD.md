# 火焰/烟雾定位模型卡

## 用途

该模型是 VisionGuard AI 比赛版的专业视觉定位分支，负责输出火焰和烟雾的类别、置信度与检测框。它不负责事故定性、隐患等级认定或处置决策；这些结论必须继续经过证据融合、知识约束与人工复核。

## 来源与完整性

- 发布仓库：<https://github.com/z11hzy/yolov8-fire-smoke-detection>
- 发布版本：`v1.0.0`
- 权重文件：`baseline_best.pt`
- 上游模型：<https://huggingface.co/rabahdev/fire-smoke-yolov8n>
- 类别映射：`0 = smoke`，`1 = fire`
- 文件大小：`6,229,802` bytes
- SHA-256：`b91633799ceb052c814b4f8b77a37efc9a40f002d528df97d74463585fa4f28f`
- 模型页许可声明：`AGPL-3.0`

权重保存在本地 `models/` 目录，不提交到 GitHub。`scripts/fetch_yolo_model.ps1` 从固定发布地址下载，并在落盘前校验完整哈希。

## 公开结果口径

发布方在固定测试集、置信度 `0.25`、NMS IoU `0.30`、评价 IoU `0.50` 下报告：Precision `0.7187`、Recall `0.7143`、F1 `0.7165`。其中火焰 Recall `0.6758`，烟雾 Recall `0.7909`。VisionGuard的高召回比赛配置采用置信度 `0.10`，该值由外部固定验证集选择，不能与发布方指标混用。

这些数值属于发布方测试，不是 VisionGuard AI 的系统级成绩，也不能证明工业现场泛化能力。比赛材料若引用，必须同时注明数据来源、阈值与验证边界。

## 已知限制

- 小目标、遮挡、低照度、蒸汽、云雾、强光和相似色区域可能造成漏检或误检；
- 图像级分类模型只能对可见火焰进行整图确认，不能替代烟雾定位；
- 输出仅用于比赛演示与辅助研判，不得直接触发无人值守的高风险控制动作。
